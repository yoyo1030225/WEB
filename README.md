# 個人網頁作品集

歡迎來到我的個人網頁專案！這是一個簡潔而優雅的個人介紹網站，使用現代化的網頁技術構建。

## 📋 專案簡介

這個網站展示了我的基本資訊、專業技能和聯絡方式。設計簡潔美觀，並採用響應式網頁設計，可在各種設備上完美顯示。

## 🌐 網頁結構

### 頁面

- **首頁 (index.html)** - 主頁面，使用 Vue.js 動態展示歡迎信息
- **關於我 (aboutme.html)** - 詳細的自我介紹頁面，包括教育背景、技能和聯絡資訊

## 🛠️ 技術堆疊

- **Vue.js 3** - 前端框架
- **HTML5** - 網頁標記語言
- **CSS3** - 樣式表和響應式設計

## ✨ 功能特色

- ✅ 響應式網頁設計，適配各種螢幕尺寸
- ✅ 使用 Vue.js 實現動態內容
- ✅ 現代化的 UI 設計，包含平滑動畫效果
- ✅ 易於自訂和擴展

## 🚀 如何使用

1. 克隆此專案或下載文件
2. 在瀏覽器中直接打開 `index.html` 文件
3. 點擊「認識我更多」按鈕可前往關於我的頁面

## 📝 自訂說明

要修改網站內容，請編輯以下內容：

### 修改歡迎語
在 `index.html` 中找到以下部分：
```javascript
greeting: "Hello, 我是 MingYou！"
```
將其替換為你想要顯示的文字。

### 修改個人資訊
在 `aboutme.html` 中修改個人名字、職位、技能和聯絡資訊。
